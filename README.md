# 🍳 Kitchen Game

A fun and fast-paced kitchen simulation game built with Unity and C#. Inspired by cooking games like *Overcooked*, this project focuses on managing food orders, cooking mechanics, and time-based challenges.

## 🎮 Game Features

- 👨‍🍳 Cooking stations with multiple recipes
- ⏱️ Time-bound challenges and orders
- 🔥 Burnt food penalties and score tracking
- 🎮 Single player (Multiplayer support in development)
- 🧠 AI-controlled characters (optional)

## 🛠️ Tech Stack

- **Engine:** Unity
- **Language:** C#
- **Graphics:** ShaderLab, HLSL
- **Version Control:** Git
